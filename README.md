# 📊 People Analytics Dashboard

## 📌 Project Overview
The People Analytics Dashboard is an interactive Power BI project designed to analyze employee data and provide actionable workforce insights. It helps HR teams and business leaders monitor employee status, compensation trends, department performance, and bonus distribution across different countries and cities.

---

## 🎯 Objectives
- Analyze employee compensation and bonus trends.
- Monitor workforce status (Active, Left, On Leave, Resigned).
- Evaluate department-wise performance.
- Compare bonus distribution across countries and cities.
- Support data-driven HR decision-making.

---

## 📈 Dashboard Features

### Employee Status Analysis
- Active Employees
- Left Employees
- Employees On Leave
- Resigned Employees

### Bonus Analysis
- Bonus by Country Wise City
- Department Wise Bonus Distribution

### Salary Analysis
- Salary by Age Wise Performance
- Employee Compensation Overview

### Interactive Capabilities
- Dynamic Filters
- Cross-Visual Interactions
- User-Friendly Layout
